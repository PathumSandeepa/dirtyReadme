Auto evolve

It updates itself at midnight.

Add one optional GitHub Action file and let your profile stay fresh every night without touching it again.

.github/workflows/evolve-creature.yml
name: Evolve Cyber Creature & Profile Details

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

permissions:
  contents: write

concurrency:
  group: evolve-creature
  cancel-in-progress: true

jobs:
  evolve:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v7

      - name: Setup Node.js
        uses: actions/setup-node@v7
        with:
          node-version: "22"

      - name: Install Sharp WebP encoder
        run: npm install --no-save --prefix /tmp/creature-deps sharp

      - name: Fetch Live Telemetry & Regenerate Animated creature.webp
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          PROFILE_PAT: ${{ secrets.PROFILE_PAT }}
          GITHUB_USERNAME: ${{ github.repository_owner }}
      # Commits updated creature.webp, creature-config.json and README.md

  1. You commit

    Push work to your public repositories throughout the day as you normally do.

  2. Midnight run

    GitHub Actions triggers the scheduled workflow at midnight UTC.

  3. README updated

    Your fresh commit total and evolved creature image commit back to your profile repo.
